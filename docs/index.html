Why dhole?

🔍

Deep scanning

Scans Makefiles, shell scripts, GitHub Actions, GitLab CI, Dockerfiles, Justfiles, Taskfiles, and docker-compose files.

🎯

Smart matching

Word-boundary detection means node_modules won't false-positive on node.

📋

Version detection

Automatically detects installed versions by trying --version, -v, and version with timeout protection.

🤖

CI-ready

Quiet mode (--quiet) returns only an exit code. Drop it into any CI pipeline.

⚡

Instant results

Pure Rust, no regex crate, no config files. Tool checks fan out across threads so a project with dozens of dependencies still completes in milliseconds.

📦

60+ tools recognized

Docker, kubectl, aws, terraform, cargo, npm, python, gh, deno, bun, mvn, gradle, gcc, and many more out of the box.
